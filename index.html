SkillTrust Academy · Digital Certificateระบบออกและตรวจสอบใบรับรองดิจิทัลบน Ethereum

ตรวจสอบความถูกต้อง (Verify Certificate)

ค้นหาด้วยรหัสใบรับรอง หรือสแกน QR Code บนใบรับรอง แนบไฟล์ PDF เพื่อตรวจว่าเอกสารไม่ถูกแก้ไข (ไม่บังคับ)

ประวัติใบรับรอง (Certificate Dashboard)

แสดงใบรับรองทั้งหมดที่ผูกกับ Wallet ที่เชื่อมต่ออยู่

ออกใบรับรอง (Issue Certificate)

เฉพาะ Issuer ที่ได้รับสิทธิ์ ระบบจะคำนวณ Hash ของไฟล์ PDF และ Hash ของข้อมูลผู้รับในเบราว์เซอร์ แล้วส่งขึ้นเชนเฉพาะ Hash – ไม่มีชื่อหรือข้อมูลส่วนบุคคลขึ้น Blockchain

เพิกถอนใบรับรอง (Revoke Certificate)

เฉพาะ Admin / Issuer ใบรับรองจะถูกทำเครื่องหมายว่าเพิกถอน แต่ประวัติการออกยังอยู่ครบ
